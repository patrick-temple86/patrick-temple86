# Hey, I'm Patrick

I'm a network engineer and lifelong tech enthusiast with 20+ years of experience working with large-scale networks and telecommunications infrastructure. Outside of work, I enjoy experimenting with Linux, building out my home lab, automating repetitive tasks, and figuring out how things work.

This GitHub is where I'm sharing projects, useful scripts, experiments, and tools I build along the way.

## What I'm into

- **Networking:** Routing, switching, DOCSIS, CMTS/CCAP, fiber optics, and network troubleshooting
- **Linux & infrastructure:** Linux administration, Proxmox VE, virtualization, containers, and self-hosted services
- **Automation:** Python and Bash scripts that make everyday tasks easier
- **Data & monitoring:** Collecting, analyzing, and visualizing system and network performance data
- **Home lab:** Testing new ideas, breaking things, fixing them, and learning something in the process

## What you'll find here

I'm building a collection of practical projects, including:

- Network configuration analysis and validation tools
- Linux and home lab automation utilities
- Infrastructure monitoring and reporting experiments
- Other projects that solve problems or satisfy my curiosity

## A little more about me

My professional background is mostly in large-scale cable and service-provider networks, but I'm always interested in expanding into other areas of technology. I particularly enjoy projects that bring together networking, Linux, scripting, and data analysis.

Most of what I share here starts with a simple question: *Can I make this work better—or automate it?*
